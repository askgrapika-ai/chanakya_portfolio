## 📁 Repository Structure

Both versions are maintained as completely separate, independent files:

```
├── v2/                     # Current Portfolio (Version 2)
│   └── index.html          # Interactive modern single-page experience
├── v1/                     # Classic Portfolio (Version 1)
│   ├── index.html          # Classic landing page
│   └── work.html           # Classic portfolio work gallery
├── assets/                 # Shared media, videos, images, and documents
├── index.html              # Root redirect (instantly loads /v2/)
└── README.md
```

- **Version 2 (Active):** Navigate to `v2/index.html` or open root `/`
- **Version 1 (Archive):** Navigate to `v1/index.html`
